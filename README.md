# ECE Correl Quiz Trainer

Single-file offline quiz app for **ECE Correlation exams** (Mapua University, 1st Term S.Y. 2026–2027).

- **14 topics** · **456 questions**
- Runs entirely in the browser — no server, no dependencies, no install
- Dark theme, keyboard-friendly, progress tracking per topic
- Questions derived from lecture PowerPoints (Prof. Engr. Herbert V. Villaruel, some by Engr. John Louis Lagtamada)

## Features

- Pick a topic to start a quiz; questions are shuffled each run
- Multiple-choice with instant feedback and explanation
- `Next` / `Skip` controls, a running score, and a review of your answers at the end
- Filter by difficulty and topic to focus your review
